# Terminal

A mini terminal in Python — built from scratch to understand how Linux works.

## Commands

| Command | What it does |
|---|---|
| `ls` | list files in current directory |
| `cd` | change directory (with error handling) |
| `pwd` | print working directory |
| `mkdir` | create a directory |
| `rm` | remove a file or empty directory |
| `rename` | rename a file |
| `move` | move a file to another directory |
| `hard` | create a hard link |
| `symbolic` | create a symbolic link |
| `exit` | quit |

## Run

```bash
python3 terminal.py
